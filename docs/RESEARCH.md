# Research Summary

This project uses research as fuel for rituals and product shape, not as a static report.

## Inspiration Clusters

- Cyberdeck: a small dedicated field terminal with personality, portability, and purpose.
- Tamagotchi: persistent state, care loops, mood, growth, ritual.
- AI companion hardware: cloud intelligence becomes meaningful when it has a body and daily habit.
- Travel translator: short high-value phrases, large readable output, low social friction.
- Ambient companion: small prompts, reminders, observations, and presence.
- Terminal games/TUIs: terminals become charming when they commit to a world.
- Local-first AI memory: inspectable, portable context is a product surface.
- Agent activity tools: traceability and permissions matter when tools act on the system.

## Implemented Mapping

- `HERMES`: inner consciousness.
- `COUNCIL`: Hermes inner judgment plus cloud outer voice.
- `RADAR`: external community/product inspiration as playable cards.
- `TOYS`: installed terminal toys as room rituals.
- `heartbeat`: time passing and autonomous reflection.
- `web cockpit`: non-command-line surface that foregrounds identity, body state, current heading, next action, Bridge, and quick layer contact.

## Current MVP Formula

`Pocket Soul Deck = AI Tamagotchi + pocket cyberdeck + Hermes inner consciousness + web cockpit + travel log + translator + terminal arcade`.

## Research Tools

- DeerFlow and opencli for broad multi-platform research.
- Board: static `research-radar.sh` when network or runtime is limited.

## Research Flow

Use broader tools for sources that need browsers, accounts, or heavier runtime:

```text
GitHub / Kickstarter / Reddit / Hacker News / Product Hunt / YouTube / X
  -> DeerFlow/opencli summary
  -> short radar card
  -> board state/radar-*.md
  -> RADAR mode, HERMES mode, or heartbeat
```

The board should receive distilled ideas, not giant scraped dumps. A good radar card has:

- source
- observed desire
- toy/ritual idea
- smallest board implementation
- why it makes the resident feel more alive
